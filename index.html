01 — About

A bit about how I work.

Final-year Software Engineering student at SZABIST Hyderabad. I build apps where the numbers have to add up — finance, stock, accounting and booking systems — for web (Node.js, PHP, PostgreSQL) and mobile (Flutter).

HISAB is an offline-first Android finance app: balance changes are applied inside atomic database transactions, behind a PIN/biometric lock, with installable builds on GitHub Releases. SkyJourney's booking API prices every booking on the server and row-locks seat inventory so the last seat can't be sold twice. I've also built a Java/JSP accounting system with vouchers and ledgers.

Currently doing a 6-week remote internship in AI Automations at DevelopersHub Corporation. Looking for a junior software engineering role (full-stack or mobile) where I can keep shipping real products. Open to remote or on-site.
